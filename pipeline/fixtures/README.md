# fixtures

Uložené reálné vzorky vstupů (HTML, XML, JSON, CSV) pro testy scraperů.

**Bez fixture se scraper nepřijímá.** Když město změní web nebo formát feedu, testy
proti fixtures padnou a bude jasné, který zdroj se rozbil a kde.

U každé fixture uveďte v názvu zdroj a datum stažení, například:
`ofn-uredni-deska-2026-09-03.json`.
